# 원본 UI에서 추출한 그림

출처: 사용자가 제공한 `인수인계/주식왕시뮬레이션_UI개편_원본.pdf`.
PDF 내부의 원본 래스터 그림에서 필요한 영역을 추출했다. 새 이미지를 생성하지 않았다.
금액, 시세, 차트, 알림 개수는 별도의 실제 게임 데이터로 표시한다.

- 2쪽: 상단 그림, 설정 및 상태 아이콘, 하단 메뉴 아이콘 대부분
- 4쪽: 로딩 그림
- 5쪽: 보상 그림과 보상/성장/우편 아이콘
- 7쪽: 홈 바로가기 6종과 하단 설정 아이콘
- 홈 바로가기 중 같은 기능/문구인 4개는 원본 글자까지 사용한다.
- 이벤트 자리는 출석/친구 기능으로 연결하며 아이템·테마를 추가하지 않는다.
- 원본에 고정된 알림 숫자와 N 표시는 실제 알림으로 오인되지 않게 표시 영역에서 제외한다.
