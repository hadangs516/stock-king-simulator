휴대폰 서버 업데이트와 관리자 접속

게임 화면은 자동 배포합니다. 아래 내용은 Google Apps Script 서버 소유자가 해야 하는 서버 업데이트와 비공개 관리자 설정입니다.

1. 기존 서버 업데이트

Android Chrome 기준으로 안내합니다. 오른쪽 위 ⋮ → 데스크톱 사이트를 켜고 가로 화면으로 보면 편합니다. 다른 기종에서도 데스크톱 웹사이트 요청 기능을 사용할 수 있습니다.

휴대폰의 실제 Apps Script 편집기는 아직 검증하지 못했습니다. 큰 코드의 전체 선택·붙여넣기가 기기와 키보드에 따라 어려울 수 있습니다. 선택/붙여넣기 메뉴가 작동하지 않으면 PC 또는 외장 키보드가 필요합니다.

  1. 기존 Apps Script 프로젝트 열기. 서버를 만든 Google 계정으로 로그인합니다.
  2. 현재 Code.gs 전체 내용을 메모 앱 등에 복사해 백업합니다.
  3. 아래 버튼으로 최신 서버 코드 전체를 복사합니다. 프로젝트의 기존 Code.gs 전체 내용을 선택하고 교체한 뒤 저장합니다. 기존 통합 Code.gs 한 파일을 사용하는 서버 기준입니다. 여러 파일로 관리 중이면 대응 파일만 갱신해야 합니다.
    코드 파일 다운로드

  4. 오른쪽 위 배포 → 배포 관리 → 현재 배포 → 연필(수정) → 버전: 새 버전 → 배포. 실행 계정과 접근 권한은 기존대로 둡니다. 새 배포를 별도로 만들지 않습니다.
  5. 게임을 새로고침하고 로그인·현금·보유종목·예약·기록을 확인합니다. 서버 업데이트 후 주가 변동 확대와 조회 최적화가 적용됩니다.

setupStockKing는 실행하지 마세요. 기존 시트·데이터·트리거를 삭제하거나 다시 만들지 않습니다. 문제가 있으면 배포 관리에서 직전 버전으로 되돌릴 수 있습니다.

2. 관리자 접속 설정

관리자 접속은 계정 로그인 → 관리자 계정 지정 확인 → 추가 관리자 인증 순서입니다. 계정 비밀번호 4자리와 추가 관리자 암호는 별개입니다.

계정 로그인부터 실패한다면

“아이디 또는 PIN이 올바르지 않습니다”는 계정이 없거나 해당 계정의 PIN이 다르다는 뜻입니다. 관리자 계정 지정만으로 회원 계정이 생기지는 않습니다. 기존 계정을 확인하고, 아직 만든 적이 없는 아이디라면 게임에서 먼저 회원가입합니다. 이미 있는 계정의 데이터를 초기화하지 마세요.

로그인은 되는데 관리자 메뉴가 없다면

  1. 위 Apps Script 프로젝트에서 왼쪽 톱니바퀴(프로젝트 설정) → 스크립트 속성으로 이동합니다.
  2. ADMIN_NAMES 값에 관리자 로그인 아이디를 입력합니다. 여러 명이면 쉼표로 나눕니다. 이미 다른 관리자 값이 있다면 보존하고 추가합니다.
  3. 저장 후 게임에서 로그아웃했다가 다시 로그인합니다. 설정 → 관리자 모드가 표시되는지 확인합니다.

추가 관리자 암호를 아직 설정하지 않았다면

  1. 스크립트 속성에 ADMIN_SECRET_SETUP을 추가하고 16자 이상 임의의 새 암호를 직접 정해 저장합니다. 계정 PIN을 이 값으로 사용하지 않습니다.
  2. 편집기로 돌아가 상단 함수 선택에서 configureAdminSecret을 골라 실행합니다. Google 권한 요청이 나타나면 서버 소유 계정으로 확인합니다.
  3. 성공하면 ADMIN_SECRET_HASH가 저장되고 임시 원문 속성은 삭제됩니다. 이 암호는 본인이 별도로 기억해 둡니다.
  4. 게임 로그인 카드의 관리자 로그인을 펼쳐 추가 암호를 입력한 뒤 로그인하거나, 일반 로그인 후 설정 → 관리자 모드에서 인증합니다. 운영 권한은 15분 동안 유지됩니다.

이 단계는 설정 값 변경입니다. 위 함수가 이미 현재 서버 코드에 있으면 이 설정만으로 새 코드 배포를 다시 할 필요는 없습니다. 실제 서버의 계정/PIN/속성 값은 여기서 확인하거나 변경하지 않았습니다.
