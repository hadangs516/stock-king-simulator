# 2026-10-09 UI 2차 요청 / 0.1.11

아래 구현·검증 기록과 마지막 배포 기록을 구분한다. GAS 업데이트는 프런트 배포와 별도다.

## 사용자 요청 대조표
1. 계정 설정 팝업: 초기화·백업·불러오기·계정 삭제. 기존 인증/최종 확인 보존.
2. 용어 사전 별도 화면, 도움말 토글, 모든 기존 용어 뜻과 게임 사용 예시.
3. 하단 아이콘 사진 배경 제거: 초록색 메뉴와 어울리는 입체 벡터 아이콘 사용.
4. 제공 로딩 일러스트, 실제 단계 문구, 하단 버전, 5초 무작위 팁. 100개는 사용자와 초안 확정 필요.
5. 매수·매도 아이콘 불투명 표시.
6. 기사 제목/본문 확대와 문단 구성.
7. 알림 즉시 읽음 및 브라우저 보관, 백그라운드 재시도.
8. 출석 30칸 5열, 작은 화면에서도 전체 보상표 확인.
9. 거래소/자산 글자 확대; 거래소 목록 미니 차트 제거.
10. 계정·회차별 목록/로그/설정 저장, 서버 대조. 실시간 주문 승인·실제 잔액은 서버 기준.
11. 뉴스 목록 그래프 제거, 제목/요약 확대.
12. 대화 캐시·즉시 말풍선·빨강 전송중 → 서버 확인 후 초록 전송완료 1초.
13. 로그인 화면을 기존 금색/초록색 일러스트 디자인과 맞춤.
14. 부자연스러운 사진 조각을 반복하지 않음. 원본은 보존.
15. 출석 받기 클릭 시 팝업 즉시 종료, 서버 수령 확인 후 도장.
16. 로그인 응답에서 출석 준비, 자동 출석창 닫기 금지; 오래된 화면은 조회 선행.
17. 화면 이동 시 조회 취소·로딩 해제·늦은 응답 차단. 이미 보낸 거래/보상/메시지는 중복 방지 위해 결과 확인.
18. 3~10일 게임에 맞춘 변동 확대. 가상 시뮬레이션으로 제한/결정성/등락 분포 검증 완료.
19. 로그인 진입 BGM 재생 시도, 자동재생 제한 시 첫 터치/키 입력 재시도. 기기 음량 선택 유지.
20. 효과음 슬롯 유지, 제공받기 전 새 효과음 생성/삽입 없음.

## 참고 자료 확인
- 새 PDF 11장과 기존 PDF 13장을 렌더링하여 대조. 새 PDF에는 알림·채팅·자산·경제·친구·종목·매수 화면이 있다.
- 두 PDF에서 별도의 출석 보상표와 로그인 입력 화면은 확인되지 않았다. 로딩 그림은 기존 PDF 4페이지를 기준으로 기존 원본 일러스트 재사용. 출석/로그인은 같은 시각 스타일로 구현하고 사용자 후속 참고본이 있으면 대조해야 한다.
- 사용자 팁 말투 예시: “주식 용어 사전에서 모르는 용어를 찾아볼 수 있습니다”, “친구와 함께 플레이 해보세요!”, “좋은 아이디어를 제안하면 보상받을 수 있습니다!” 조건부 보상은 채택 조건 명시.

## 보존/배포 제한
- 사용자 삭제 기획기록·docs/V0_UI_GUIDE.md·비공개 자료 보존. 운영 계정으로 테스트하지 않는다.
- 새 팁 100개는 검토용 초안. 사용자 확정 전 게임에는 예시 기반 3개만 사용.
- 브라우저 캐시는 인증을 대체하지 않는다. 계정/회차 분리. 운영 데이터 마이그레이션 없음.
- 기존 서버 최적화 0.1.10은 GAS 배포 대기. 이번 신규 작업까지 완료한 후 새 통합 서버 파일로 안내를 갱신할 것.


## 구현과 검증 기록
- 요청 1~3, 5~7, 9~12, 15~20의 구현 완료. 4번 로딩 기능은 구현했고 꿀팁100은 사용자 검토 대기. 8/13번은 두 PDF에 별도 출석/로그인 입력 화면이 없어 같은 디자인으로 구현하고 후속 원본 이미지 대조는 남긴다.
- 전체 128개 자동 테스트 통과(실패 0). 문법/참조 검사 통과. 중요한 회귀는 실패를 먼저 재현하고 수정 후 통과 확인.
- 320/375px 각각 10화면 가로 넘침·실행 오류·배너 침범 없음. 계정 설정의 초기화/백업/불러오기/삭제 진입점, 용어 사전 페이지와 토글, 30칸 출석 보상표의 내부 스크롤 없음 확인.
- 320×667px 지연/끊김 시험: 자동 출석창 X 숨김·ESC 차단, 받기 클릭 즉시 닫힘, 채팅 pending → 서버 확인 → sent 1초, 캐시 대화 즉시 재입장, 조회 중 화면 이동 취소, 읽음 오프라인→새로고침→연결 재시도 확인.
- 최종 브라우저 병렬 실행은 검증용 프로세스 메모리 한도/Chrome crash로 실패했으며 직렬 실행으로 재검증. 제품 버그로 보고하지 않는다.
- 별도 읽기 전용 코드 리뷰에서 supportCreate 요청 식별자 보존과 오래된 캐시 이후 대화 gap cursor 문제 발견. 기존 mutate 재시도 복구 및 누락 이력 커서 보존·시간순 병합 수정. 관련 테스트 통과.
- 요청한 캐시는 계정+회차별로 분리한다. 친구 목록·로그를 뒤에서 준비한다. 로그는 한 번에 최대 300건씩 모든 페이지를 순차 보관하고, 화면에 표시한 대화/이전 메시지도 누적 저장한다. 브라우저 용량 한도/차단 시 메모리로 계속 동작한다. 로그인 화면은 전체 이력 다운로드를 기다리지 않는다.
- 변경 대기 읽음/설정은 브라우저에 요청 식별자와 함께 저장하고 조용히 재시도한다. 거래/출석 실제 금액은 서버 확인 후 반영한다. 이미 제출한 쓰기는 화면 이동 후에도 결과 확인해 중복 처리 방지.
- 서버의 optional lightweight 목록/대화/로그 응답은 해당 데이터만 반환한다. 인증·정산·상태 저장은 기존 흐름을 거친다. 기존 protocol 1 서버는 이 옵션을 무시하므로 새 프런트와 호환된다.
- 가상 24종목×7일 분봉으로 로그 조회 5회 교차 측정: 전체 응답 중앙값 826.67ms / 271,206B → 목록만 154.38ms / 752B. 로그 JSON 동일. 로컬 계산 비용이며 실제 GAS/Google Sheets/네트워크 응답 시간은 별도다. 재현: node tools/measure-list-read.cjs.
- 주가 개별 분봉 노이즈 계수는 기존 0.008 → KOSPI 0.022 / KOSDAQ 0.032. 시장/산업 공통 변동도 확대. 일반 종목 ±30% 일일 제한, 양방향 등락, 지연 재접속 결정성, 거래·예약·세금 회귀 통과. 기존 주가/계정 이력 초기화 없음.
- 꿀팁 초안 100개는 상위 인수인계/로딩_꿀팁100_검토초안.md. 사용자가 직접 검토하고 수정 번호를 알려주기로 했으므로 전체 반영하지 않았다.
- 0.1.11 통합 GAS 파일 및 기존 서버 업데이트 안내: 상위 배포자료/20261009_UI2/서버업데이트/. setupStockKing 실행 금지. 기존 0.1.10 서버 최적화도 포함한다.

- 추가 최종 검증: 320/375px 로그인·로딩 그림 비율/가로 넘침/버전 표시, 꿀팁 5초 교체, 로그인 첫 터치 후 BGM 재생 통과. 자동재생 자체는 브라우저 정책에 따라 제한될 수 있다.
- 오래 접속하지 않아 새 로그가 캐시보다 많이 쌓여도 서버 페이지 커서를 그대로 따라 전체 이력을 병합하고 시간순 정렬한다. 최대 300건 조회 제한, 계정 격리 및 관리 정보 제외 검증.
- 저장 공간 부족 시 읽음/설정 outbox 저장을 위해 다시 받아올 수 있는 캐시만 비우고 재시도한다. 인증값과 모든 계정의 outbox는 지우지 않는다. 저장 기능 자체가 차단되거나 대기 변경만으로 용량을 초과하면 메모리 유지가 한계다.
