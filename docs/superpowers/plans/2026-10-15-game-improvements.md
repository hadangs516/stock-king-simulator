# 게임 13개 요청 구현 계획

**Goal:** 출석/보상/업적/거래/관리자/프로필/친구/대화의 사용자 요청을 기존 게임에 완결된 흐름으로 반영한다.
**Architecture:** 기존 Vanilla JS/GAS와 저장 형식2 유지. 계정 social에 작은 프로필 사진/소개를 추가하고 친구 응답에 공개한다. 대화는 최근10개 예열, 진입 시50개 보강, 열린 대화2초 주기·중복 조회 방지. 서버 권한·원장·비공개 관리자 설정 유지.
**Tech Stack:** 기존 Node 회귀, 격리 Chrome, PDF 원본11장 WebP. 새 외부 서비스 없음.
**Spec:** 사용자 2026-10-15의 13개 요청 및 업적 참고 화면.

- [x] 화면 묶음: 출석 X 제거/수령 완료 닫기, 보상 뒤로가기, 하단 순서, 영수증 뉴스와 기사 관련 기업 버튼 제거. PDF 아이콘11개와 업적 카드/진행률 적용. 파일: progression-ui/nav-icons/views, 공통 CSS. 회귀를 먼저 실패시키고 구현.
- [x] 거래 묶음: 수수료 포함 최대 매수/사용가능 주수 최대 매도, +/- 한계/색, 직접 입력 오류, 비활성 색 제출과 오류 흔들기. 파일: trade-ui/app, 회귀/브라우저.
- [x] 관리자 묶음: 공지 기본 전체, 공지/보상 내부의 검색·페이지별 다중 대상 선택, 선택 유지; 플레이어/종목 현재 값 자동 채움. 파일: admin-ui, 회귀/브라우저. 실제 지급/시세 변경은 수행하지 않음.
- [x] 프로필 묶음: 설정에서 이름/소개/사진(160px WebP, 24KB 이하) 편집·제거. 서버 형식/길이 검증, 친구 목록·검색·프로필 공개, 튜토리얼 안내. 기존 금융 공개 설정 유지. 파일: Friends/AccountLifecycle, friends-ui/profile-image, 테스트.
- [x] 친구·대화 묶음: 섹션별 로딩/빈 상태, 로그인 예열 즉시 화면 연결, 순위 예열, 대화별 최근10개 묶음 예열/캐시, 진입 시 나머지 보강. 열린 대화2초 간격 직렬조회/배경 중지·계정 변경 보호. 파일: Chat/Engine/Friends, chat-ui/friends-ui/app/api. 성능·권한·페이지/새 메시지 순서 회귀.
- [ ] 통합: 전체 테스트/구문/이미지·모바일2회 이내 점검, 최종 코드 검토, 버전0.1.24 및 캐시, 공개 서버 통합본 재생성. 운영 소스 대조 후 관리자 비공개 bootstrap/ScriptProperties/운영 장부를 보존한 기존 GAS 배포 갱신. setup/저장소 전환 금지. 담당 파일만 커밋/push, Pages/API/인수인계 증거 기록.
