# 2026-10-13 일반 로그인에서 관리자 접속

사용자가 지정한 관리자 계정을 일반 로그인 화면에서 인증하고 곧바로 관리 화면으로 연결한다. 로그인 화면의 별도 관리자 입력칸과 설정 안내를 제거했다. 관리자 인증 만료 시 서버에 다시 인증하여 별도 암호창 없이 갱신한다.

- 최초 관리자 설정은 소유자에게 전달하는 비공개 서버 통합본에서만 제공한다. 실제 PIN과 검증값을 공개 저장소나 배포 웹사이트에 포함하지 않는다.
- 최초 설정은 기존 SIGNING_KEY, 시트 연결, 다른 관리자 설정을 보존하고 관리자 속성 3개만 추가한다. 이후 공개 통합본으로 교체해도 속성이 유지된다. 이전 비공개 통합본으로 현재 설정을 덮어쓰지 않는다.
- 관리자 PIN은 원장에도 원문 대신 계정 ID와 서버 서명키에 묶인 검증값으로 저장한다. 계정 역할도 별도 서버 서명으로 검증한다. 기존 일반 계정 인증 방식은 그대로다.
- 공개 회원가입으로 관리자 아이디를 선점할 수 없다. 기존 같은 이름 계정이 있으면 중복 접속 확인 전에는 계정, 비밀번호, 기록이 변하지 않는다. 소유자 인증과 명시적 접속 전환 후 기존 ID와 기록을 보존한다.
- 세션 전환, 로그아웃, PIN 변경 시 기존 관리자 인증과 대리 접속이 폐기된다. 인증은 15분 만료를 유지하며 실제 관리자 권한은 서버에서 확인한다.
- 늦게 도착한 관리자 현황이나 자동 인증 응답이 다른 계정 또는 다른 화면에 반영되지 않는다.

검증: 전체 163개 테스트 통과, 20개 서버 소스와 프런트 정적/구문 검사 통과. 합성 서버의 Chrome 320×568, 375×812, 480×812에서 일반 관리자 로그인 → 관리 화면 → 새로고침 → 인증 만료 후 갱신 확인. 일반 계정의 홈 진입도 유지된다. 실제 운영 서버 설정 및 배포 적용은 별도로 기록한다.

비공개 통합본은 저장소 바깥 `배포자료/20261013_관리자로그인/주식왕_서버_관리자설정.private.gs`에 있다. 최초 서버 반영 전에는 새 관리자 로그인 완료를 주장하지 않는다.
