# 숫자·보상·타이포그래피·뉴스 UX 개선 계획

사용자 승인 범위: 돈을 실제 금액 상자에서 빠르게 정수로 증가시키기, 총자산의 모든 돈 표시와 시계방향 도넛을 1.5초 이내에 표시하기, 제공된 돌아가기 그림 반영, 전체 UI의 폰트·줄바꿈·강조·색 점검, 뉴스 그림 반복 회피, 보상 수령 즉시 화면 반영 및 뒤에서 서버 확인. 추가 확인을 위해 멈추지 않고 버그 방지까지 검증한다.

**Goal:** 보상과 자산의 반응을 즉시 보여 주고 원본 게임 스타일의 글자와 UI 품질을 통일한다.

**Architecture:** 기존 클라이언트에 정수 카운터와 돈 전용 임시 표시를 추가한다. 확정 스냅샷은 변경하지 않으며 같은 요청 ID로 서버가 수령을 최종 확정한다. 뉴스 삽화는 공개 기사 ID에 고정된 브라우저 표시 매핑으로 최근 중복을 피하고, 기사 사실과 서버 원장을 변경하지 않는다. 실제 한글 서체·그림을 자체 호스팅하고 마지막 공통 스타일로 기존 금색/녹색 UI를 보존한다.

**Tech Stack:** Vanilla JavaScript, requestAnimationFrame, Web Animations API, 자체 호스팅 한글 WOFF2, 기존 Node 테스트, 격리 Chrome.

## 보존 조건

- 기존 기획기록 삭제 표시, 미추적 V0_UI_GUIDE, 첨부 원본, 모든 비공개 자료 보존.
- 현재 서버7/형식2와 관리자 설정 유지. 서버 setup/재전환 없이 기존 서버의 수령·중복 방지 사용.
- 돈의 임시 표시를 거래·주문 검증의 근거로 사용하지 않는다. 확정 실패는 되돌리고, 응답 유실은 같은 요청으로 재확인한다.
- 모바일·키보드·접근성·동작 줄이기 설정 유지. 최종 돈은 정확한 정수이며 숫자와 단위를 잘라 표시하지 않는다.
