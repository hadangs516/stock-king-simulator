## 구조와 구현 순서

별도 빌드 없는 루트 HTML/CSS/JS와 Apps Script 서버. 서버가 인증, 한국 날짜, 공통 분봉, 체결, 잔액과 권리를 결정한다. 모든 변경은 ScriptLock 아래에서 처리하고 Sheets 원자적 batchUpdate로 저장한다. PIN과 관리자 강화 인증값은 클라이언트/저장소에 포함하지 않는다.

1. [x] `server/Engine.gs`, `Accounts.gs`, `Trading.gs`: 계정·공통 시장·즉시/예약 거래. Node 실제 엔진 테스트에서 인증·자정·가격·중복·잠금 검증 후 커밋/푸시.
2. [x] `server/Funds.gs`, `Events.gs`: ETF 장부·기업 달력·뉴스·배당·업적·백업. 장부 보존·수령/초기화·미접속 재처리 검증 후 커밋/푸시.
3. [x] `server/Admin.gs`, `Storage.gs`, `Code.gs`: 관리자 운영·대리 접근·선택 공지/보상·원자 저장·배포 도구. 권한과 비공개 응답·재시도 검증 후 커밋/푸시.
4. [x] `index.html`, `styles.css`, `js/`: 세로형 5개 탭·상세/주문/기록/총자산·설정·관리자. 브라우저 실제 흐름/모바일 검증 후 커밋/푸시.
5. [x] PWA·아이콘·오디오·오류 안내·설치 설명. 정적 파일 연결과 오프라인 조작 차단 검증.
6. [ ] Apps Script 설치/권한 승인/배포, Pages와 실제 서버 통합 검증. 사용자 계정 조작이 필요한 외부 단계는 정확한 설치 문서 제공.

## 구현 시 선택한 가상 게임 규칙

- ID 2~12자 완성형 한글, NFC 정규화. 세션 30일(로그인 유지)/12시간, 무입력 5분 이후 플레이 집계 중단. 서버에서 계정별 활동 구간의 합집합으로 다중 탭 중복 방지. 30분 이상 접속 간격을 새 자동 로그인으로 집계.
- 과세는 현실 세법 재현이 아닌 `game-tax-v1`: 주식 매도 게임 거래세 0.15%, ETF 매매 거래세 0%, 개인 배당·분배 게임 소득세 15.4%. 매수/매도 수수료 각각 0.05%, 원 미만 올림. 향후 변경은 새 규칙 버전으로 적용.
- 호가 20초 및 시장 분/가격 일치 검증, 1주/1원. OCO는 수량 한 번 잠금, 한쪽 체결 후 반대쪽 취소. 정지 중 대기, 폐지/분할 시 예약 취소. 만료시각 이상 체결 금지.
- ETF 3개, 구성자산 장부에서 iNAV 계산. 가상 유통시총 비중, 구성당 최대 35%, 최소 4종목(전체시장 24종목). 연 0.2% 현실 시간 보수. 괴리는 ±0.5% 내 수렴 모사.
- 일요일 00시 실적·배당 공지/ETF 재조정, 18시 주식 배당 권리/배당락, 19시 펀드 배당 입금 및 개인 수령 가능, 20시 ETF 권리/분배락, 21시 분배 수령 가능. 분배는 수령한 배당 현금 재원 이내. 배당락 때 전일 기준가도 같은 금액만큼 조정.
- 비상장 유효 시세 없는 보유분은 총자산에 0원으로 보수 평가하고 수량/원가 별도 보존. 이는 회수금 확정이 아니다.
- 수급 보정은 15분간 3계정 이상 순거래, 계정별 가상 유동성의 2% 기여 제한, ±5% 상한. 기존 보정의 80% + 새 목표의 20%, 가격에 비율 한 번 적용. 관리자 거래 제외.
- 산업은 6개이므로 산업 탐색 목표 3/5/6으로 조정(기존 8은 달성 불가). 개인 간 거래·대규모 부분 체결은 기존 후속 범위, 랭킹 등 삭제 요구는 구현 제외.

### 0.1.1 최종 로컬 검증

- 브라우저에서 관리자 강화 인증 → 플레이어 선택 → 게임머니 10,000원 등록 → 대상 대리 화면 수령 → 삼성전자 2주 매수 → 목표가 등록 → 원래 플레이어 상세 복귀 확인. 대리 접속 전후 대상 로그인 횟수는 1회로 동일.

- 시장 직접 분할은 원 단위 평가액을 보존하도록 현재가/기준가가 비율로 나누어지는 경우만 허용. 배당 정책은 다음 일요일 공시부터 적용하며 주가보다 큰 지급은 감액 공시.
- 저장 실패 시각과 마지막 트리거 시각/소요시간은 실제 GAS 관리자 화면에만 제공한다. 외부 서비스 장애나 승인 상태를 로컬 테스트로 대신 확인한 것으로 표시하지 않는다.

- setupStockKing을 실행하여 Google 권한 검토 화면까지 도달했다. 현재 'Google에서 확인하지 않은 앱' 화면에서 소유자 조작을 기다린다. 권한 승인, 원장 생성, 트리거 설치, 기존 웹앱 새 버전 배포 및 실제 API 통합은 아직 완료되지 않았다.
- 관리자 강화 암호나 실제 PIN은 공개 코드에 추가하지 않았다.

### v0 후속 요청

현재 서버 설치·검증 작업 후 v0에 넣을 프롬프트와 사용 순서를 제공한다. 프롬프트는 필요한 화면·버튼·기능·화면 전환을 중심으로 작성한다. 기존 설명 문구나 디자인을 답습하도록 요구하지 않는다. 사용자가 결과 코드를 전달하면 기존 기능과 데이터 연결을 유지하며 UI를 교체한다. 최종 배포는 계속 빌드 없는 HTML·CSS·JavaScript와 GitHub Pages main 루트를 기준으로 한다.


## 실제 서버 배포 검증 — 2026-09-27 후속 완료

앞선 승인 대기 기록 이후 소유자가 Google 권한 승인을 완료했다.

- setupStockKing 실행 완료, 전용 비공개 스프레드시트 생성. 기존에 제공된 다른 시트에는 연결하거나 덮어쓰지 않았다. 실제 원장 링크는 공개 문서 대신 소유자 실행 로그와 로컬 설치 안내에서 확인한다.
- marketTick 트리거 1개 설치. 21:23:27과 21:28:27 실행을 확인했고 두 실행 모두 완료됐다.
- 기존 배포 ID와 /exec 주소를 유지하여 버전 2 배포. 공개 GET에서 service=stock-king, version=1, 점검 해제 상태 확인.
- 검증용 계정 1개 생성. 앞자리가 0인 PIN으로 Chrome 로그인, 새로고침 후 로그인 유지와 원장 복원 확인.
- GitHub Pages의 실제 Chrome 화면에서 삼성전자 2주 매수. 체결가 69,977원, 수수료 70원, 출금 140,024원, 잔액 9,859,976원인 영수증 확인.
- 삼성전자 1주/조건가 100원 검증 예약 등록 → 다른 Chrome 탭에서 조회 → 취소 → 원래 탭 새로고침 후 상태 확인. 동일 브라우저의 두 탭 검사이며 독립 두 기기 검증과 구분한다.
- 자동 HTTP 검증 및 인앱 브라우저에서 리디렉션 응답이 상태 JSON/HTML로 바뀌거나 시간 초과된 사례가 있었다. 일반 Chrome의 실제 페이지 흐름으로 로그인·거래·예약·취소를 확인했다. 자동 HTTP 전체 시나리오를 통과한 것으로 기록하지 않는다.

- 관리자 실계정 지정과 강화 암호는 소유자가 비공개로 설정해야 한다. 실서버 관리자 통합·독립 두 기기·모바일 설치·운영 부하·외부 푸시는 별도 미완료 항목이다.
- v0 일반/관리자 화면 프롬프트와 코드 전달 절차를 docs/V0_UI_GUIDE.md에 작성했다. UI 자체는 변경하지 않았다.
