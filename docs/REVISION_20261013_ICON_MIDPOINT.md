# 2026-10-13 설치 아이콘 크기 중간값 조정

사용자가 이전 큰 아이콘은 잘리고 0.1.18 아이콘은 너무 작다고 확인하여 두 크기의 중간으로 조정했다. 제공 원본 `assets/favicon-transparent.png`는 그대로 보존한다.

- Android용 별도 이미지에서 그림 폭을 캔버스의 64.44%에서 80.22%로 확대했다. 이전 큰 표시의 96%와의 중간값이다.
- 원본의 가로세로 비율, 글자, 왕관, 캐릭터와 돈 그림을 유지한다. 전체 그림은 512px 원형 표시 경계 안에 들어간다. 보간과 경계를 위해 여유를 둔다.
- 원형과 둥근 사각형을 나란히 표시하여 전체 그림의 잘림이 없음을 확인했다. 0.1.18의 보수적 40% 안전 원 대신 사용자가 요청한 크기로 확대한 것이므로 모든 OS의 마스크에서 전체 그림이 보장된다는 의미는 아니다. 실제 기기의 표시도 확인한다.
- 매니페스트, 브라우저 아이콘, Apple 아이콘, 서비스 워커에 새 v20 파일명을 연결했다. 앱 이름은 `주식왕 시뮬레이션`을 유지한다.
- 뉴스 이미지나 새로운 원본 이미지는 생성하지 않았다.

증거: 저장소 밖 `배포자료/20261013_관리자로그인/icon-midpoint-preview.png` 및 `icon-midpoint-verification.json`. 원본의 비투명 픽셀을 변환하여 전체 원형 영역 밖에 놓이는 픽셀 0개를 확인했다. 이는 실제 폰의 설치항목 캐시 갱신을 대신하지 않는다.
