# v0.1.25 — 튜토리얼·뉴스·기업 선택 부담 줄이기

튜토리얼의 다음 버튼을 누를 때마다 서버 저장을 기다리던 흐름을 즉시 화면 전환 후 백그라운드 저장으로 바꿨다. 기존 계정 초기화 저장 오류 수정은 유지한다.

- 튜토리얼 다음·완료를 기존 즉시 반영 큐로 전송한다. 완료도 바로 창을 닫는다. 첫 보상 처리 중인 진행 저장은 보상 응답을 기다린다. 보상 수령 검증과 현금 확정은 서버가 담당한다.
- 진행 저장은 누적 단계로 처리한다. 중간 저장이 실패해도 이후 단계로 복구할 수 있고 오래된 응답이 단계를 되돌리지 않는다. 첫 보상을 받기 전에는 다음 안내로 건너뛸 수 없다. 다른 로그인·회차의 늦은 응답은 기존 맥락 검사로 차단한다.
- 출석 안내는 꾸준히 출석하면 더 많은 보상을 받을 수 있다는 설명으로 줄였다. 튜토리얼의 ETF 해금 날짜, 출석 금액표·연속 출석 재시작·보상표 반복 설명을 제거했다. 실제 보상과 해금 규칙은 유지한다.
- 튜토리얼의 프로필·설치·가상 투자 설명, 자산 계산의 중복 각주, 경제·알림·예약주문 안내를 줄였다. 로딩 팁은100개에서10개로 줄였다. 거래 금액·수수료·세금·손절 체결 주의·계정 삭제 확인은 보존한다.
- 자동 기업·시장 기사는 30~90분 간격에서4~6시간 간격으로 줄였다. 기본 기사16종은 쉬운 두 문장으로 썼으며 반복되는 교육용 해설을 제거했다. 일요일 기업별 실적·배당 공시는 한 건으로 묶고 개별 실적·배당 권리는 그대로 처리한다. 묶음 기사도 보유·관심종목 알림 설정과 관련 뉴스에 연결한다. 위험 공시와 관리자 공시는 별도 유지한다.
- 뉴스 기본 목록은 최근12건이며 이전 뉴스 더 보기로12건씩 추가한다. 긴 기존 기사와 주간 묶음 내역은 자세히 보기로 펼친다. 기존 원문과 공시는 저장소에서 삭제하지 않는다.
- 기본 상장 기업24개 중10개(41.7%)를 거래소·홈 추천·시장 현황·자동 일반 기사 대상에서 제외한다. 기본 선택은 코스피10개·코스닥4개, 6업종14개다. 기존 추가 상장 기업은 보존한다. 자동 신규 상장은 보이는 일반 기업14개를 넘기지 않는다.
- 제외한 기업: 리노공업·도이치모터스·구영테크·삼성SDI·에코프로·알테오젠·휴젤·카카오·카카오게임즈·클래시스. 이 기업들의 원본·가격·시세·계정 보유분·기존 주문·매도·ETF 구성자산은 그대로 보존한다. 기업 원본 삭제나 보유분 강제 정산을 하지 않는다. 기존 보유 종목은 내 자산에서 접근한다.

## 검증

- 신규 동작 회귀 테스트가 수정 전 실패하는 것을 확인했다. 전체 `npm test` 225개 통과, `npm run check` 서버22파일·manifest·HTML·JS 검사 통과. 마지막 홈 추천·시장 현황 일관성 조정 후 관련17개 테스트도 통과했다.
- 독립 검토에서 중간 튜토리얼 저장 실패 복구와 주간 묶음 알림 설정 문제를 발견해 실패 테스트를 먼저 추가하고 수정했다. 재검토에서 남은 차단 문제 없음.
- 실제 Chrome + 가상 계정 + 격리된 메모리 장부 형식2에서 보상·튜토리얼 응답을 각각3초 지연했다. 다음 버튼 연속 입력과 완료 창 닫기가 응답 전에 동작하고 차단 로딩은 나타나지 않았다. 이후 서버의 `tutorial:true, tutorialStep:8` 및 단계별 저장 성공을 확인했다.
- 실제 화면에서 뉴스12→24건 더 보기, 간결한 기사, 코스피10·코스닥4개, 제외된 종목의 기존 보유분 표시를 확인했다. 매도·시세·ETF 장부 보존은 자동 회귀로 검증했다. 운영 계정 초기화·삭제·거래로 시험하지 않았다.
