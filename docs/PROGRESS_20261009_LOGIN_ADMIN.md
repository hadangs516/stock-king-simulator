# 2026-10-09 로그인 원본·관리자 UI·휴대폰 안내 / 0.1.12

## 사용자 요청과 확인
- 사용자가 이전에 제공했다고 지적한 로그인 원본 1000007831.jpg를 다시 확인. 기존 두 PDF에 로그인 입력 화면이 없다는 사실만으로 원본 자료가 없다고 안내한 것은 확인 누락이었다. 이번 JPG를 현재 로그인/회원가입 시각 기준으로 사용한다.
- 첨부 1000007822.jpg 로딩 화면은 기존 loading-art와 같은 디자인. 기존 단계 문구/동적 팁/버전 기능 유지.
- 사용자 후속 답변: 관리자 경로를 찾지 못했고 제공한 아이디/PIN으로 일반 로그인도 되지 않음. 운영 계정 생성 여부/실제 PIN/ADMIN_NAMES/ADMIN_SECRET_HASH는 미확인. 사용자 비밀값을 코드에 넣거나 운영 계정으로 시험 로그인하지 않음.

## 변경
- 원본 JPG에서 로그인 패널 전체를 정확히 분리하여 배경으로 사용. 실제 흰 입력 카드가 원본의 인쇄된 입력 카드를 완전히 가린다. 로고는 자르지 않고 자연스러운 비율로 표시하며 아래 이미지 경계는 배경색으로 연결한다. 노란 로그인/회원가입 버튼, 사용자/잠금 벡터, 가입 비밀번호 확인/가상투자 동의, 유지 옵션과 관리자 추가 암호 연동 보존. 서버의 한글2~12자 조건은 원본2~16자보다 우선 유지.
- 관리자 계정의 관리자 모드 버튼은 설정 최상단. 기존 접힌 기타 메뉴에서 이동. 추가 인증 안내를 명확히 표시.
- 운영 현황/운영 상태/지표, 공지·고객지원/플레이어 운영/시장·기록으로 기존 동작을 정리. 검색·정렬·선택·플레이어 상세와 기존 게시/지급 확인 과정 유지.
- 관리자 조회가 로그인 변경이나 화면 이동 뒤 화면을 덮지 않도록 차단. 권한 만료 시 이전 운영 데이터를 지우고 추가 인증을 다시 요청.
- review/tips.html: 기존 검토 초안과 같은 번호100개, 휴대폰에서 검색/검토 가능. 전체 게임 반영은 여전히 사용자 수정 번호 대기.
- review/setup.html: 휴대폰 데스크톱 사이트 요청, 기존 서버 교체/새버전 배포, 관리자 계정 지정과 추가 암호 설정 안내. 소유자 Google 인증이 연결되지 않아 에이전트의 운영 GAS 배포는 불가. 실제 휴대폰 Apps Script 편집기는 미검증, 전체 선택/붙여넣기가 안 되면 PC/외장 키보드 필요.
- deploy/server-update.txt: 최신 통합0.1.12 서버 파일과 동일. 실제 비공개 속성/아이디/PIN/암호를 포함하지 않음. 기존0.1.10/0.1.11 서버 최적화와 변동성 확대를 포함. setupStockKing 실행 금지.
