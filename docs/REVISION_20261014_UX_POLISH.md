# 돈·보상·전체 화면 UX 개선 — 2026-10-14

제품 v0.1.23. 금색·녹색 게임 스타일과 기존 메뉴를 유지하며 보상 반응, 금액 모션, 글자와 그림의 품질을 통일했다. 홈 PDF 버튼은 앞서 배포된 v0.1.22를 그대로 사용한다.

- 현금이 바뀌면 실제 숫자 상자를 정수로 증가/감소시킨다. 큰 금액은 프레임마다 여러 원씩 이동하고 마지막 값은 정확히 맞춘다. 진행 중 갱신은 보이는 숫자에서 이어진다. 계정·진행·대리 맥락이 바뀌면 이전 금액을 이어받지 않는다.
- 총자산·내 자산 진입 시 상단 현금/총자산, 원형 그래프 중심, 분류별 금액, 상세 계산과 보유 종목 금액을 0부터 최대 1200ms 동안 채운다. 원형 그래프는 12시에서 시계방향으로 드러난다. 동작 줄이기 설정에서는 즉시 끝값을 보여 준다.
- 현금·배당·종목·배지·출석 수령은 누른 즉시 화면에 예상 결과를 표시하고 서버 확인을 뒤에서 수행한다. 원본 확정 스냅샷과 서버 원장은 변경하지 않는다. 확정 실패는 복원하고, 응답 유실은 같은 요청 ID로 재확인한다. 재접속에도 처음 대상 보상 ID/출석 날짜를 유지해 새로운 보상을 잘못 미리 받지 않는다. 미확정 돈을 사용하는 거래는 최종 확인까지 보호한다.
- Noto Sans KR 가변 두께 100–900과 Black Han Sans 제목 폰트를 자체 호스팅했다. 한글 본문 폰트는 현대 한글 11172자를 포함하고 제목에 없는 글자는 본문 폰트로 보완한다. OFL 라이선스를 함께 보존했다. 외부 Google Fonts 연결 없이 로드한다.
- 제목·본문·보조 설명·금액의 글자 크기와 두께, 가격 색상, 강조를 정리했다. 총자산 금액의 과도한 외곽선·그림자를 제거하고 작은 화면·큰 금액·확대 화면에서 문장과 숫자가 넘치지 않도록 배치를 조정했다. 보상 행, 알림 탭, 효과음 조절 행도 실제 점검에서 발견한 넘침을 수정했다.
- 제공된 돌아가기 버튼은 내장 ImageGen으로 바깥 배경을 제거했다. 최종 버튼 RGB는 원본에서 재사용하고 투명도만 적용해 글자와 테두리를 보존했다. 왕관은 참고 제목에서 추출하고 제목 문구는 실제 폰트로 표시한다. 공통 뒤로가기 동작과 접근성 이름은 유지한다.
- 뉴스 그림은 기사 ID별로 고정하고 최근 사용 20장을 가능한 한 피한다. 같은 기사·본문·재접속에서는 동일 그림을 유지한다. 산업 분야·금리·배당 등 장면이 맞는 후보만 사용하며 공급 지연 같은 특수 사건을 다른 특수 사건 그림으로 바꾸지 않는다. 적합한 후보가 20장보다 적으면 오래된 그림부터 재사용한다. 기존 100종을 활용하며 추가 뉴스 이미지는 생성하지 않았다.
