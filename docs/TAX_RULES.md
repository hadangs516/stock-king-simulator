일반 국내 개인의 국내 상장 주식 및 국내 주식형 ETF를 대상으로 하는 연습 규칙이다. 대주주 양도세, 금융소득 종합과세, 절세 계좌, 해외 자산, 신고·공제 절차까지 재현하지 않는다. 모든 현실 세법을 구현했다고 표시하지 않는다.

세목별 원 미만은 버림, 수수료는 기존 규칙대로 원 미만 올림이다. 실제 금융기관의 세금 합산·소액 징수·절사 절차 전체를 재현하지 않는다. 배당은 지급 예정일의 DAY로 세율을 확정하여 미수령 자산에 반영한다. 버튼을 늦게 눌러 세율이 달라지지 않는다. 예약은 실제 체결일 DAY를 적용한다. 기존 영수증과 확정 배당 원장은 소급 변경하지 않는다.

새 규칙 버전은 `kr-2026-day3-v1`. 서버 snapshot에 정책을 제공하여 프런트 예상액과 실제 계산을 맞춘다. 이전 서버 배포와 연결된 동안은 기존 세율 안내와 계산을 유지한다.
