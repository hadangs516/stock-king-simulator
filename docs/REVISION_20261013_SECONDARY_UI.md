# 2026-10-13 보조 화면 품질 통일 / 0.1.16

사용자가 참고 이미지가 없는 화면도 품질을 맞추도록 요청했다. 기존 게임 그림을 재사용하고 실제 HTML 버튼·입력·데이터를 유지하며 보조 화면을 대조했다. 뉴스 이미지나 효과음을 생성하지 않았다.

## 변경

- 친구·순위: 예전 파란색 카드 제거. 크림색/금색 카드, 닉네임 첫 글자 배지, 실제 순위/값과 내 표시, 녹색 메시지 버튼, 공개 설정 구역을 구성했다. 친구 수락·삭제·공개 범위·순위 계산·닉네임 이스케이프는 유지했다.
- 계정 팝업: 계정 식별 카드, 저장/PIN/백업/불러오기 네 관리 버튼, 로그아웃, 별도 초기화/삭제 구역으로 구성했다. 일곱 기능과 기존 비밀번호/최종 확인 절차를 보존했다.
- 경제 지표: 세 실제 수치가 큰 카드에 표시되고 DAY 3 잠금은 그대로다. 독립 SVG gradient ID를 사용하여 지표 아이콘이 하단 거래소 아이콘의 색을 바꾸지 않도록 했다.
- 기록·사전: 오래된 파란색 로그 카드와 과한 간격을 줄이고 같은 테두리/글자 크기를 적용했다. 원래 기록 필드·영수증·페이지 이동·전체 용어·게임 예시·도움말 설정·펼침 상태를 유지했다.
- 고객센터·채팅: 문의 카드와 대화 말풍선을 게임 색상으로 통일했다. 입력창을 대화 목록과 겹치던 sticky 배치에서 정상 흐름으로 변경하고 대화 높이를 화면에 맞춰 조절했다. 하단 메뉴의 레이어도 분리했다. 작은 화면에서는 초점·입력·viewport 변경 시 현재 대화/초점에만 제한해서 전송 버튼까지 보이도록 스크롤을 보완했다. 브라우저 캐시·전송 상태·재시도·개인정보 범위는 변경하지 않았다.
- 튜토리얼: 빈 공간을 줄이고 이미 있는 투명 그림, 실제 9단계 표시, 코인 그림을 사용했다. 실제 출석 지급·진행 제한/재보기 절차를 보존했다.
- 관리자: 운영 현황/그룹/실제 도구에 기존 아이콘을 사용했다. 권한·대상 선택·확인·서버 작업은 변경하지 않았다. 알림 옵션도 같은 크림색 행/49px 터치 영역으로 통일했다.
- 버전 기록이 0.1.11에서 끝나던 부분을 0.1.15/0.1.16까지 갱신했다. 새 CSS를 오프라인 캐시에 포함하고 프런트 버전을 0.1.16으로 올렸다.

## 검증과 적용 경계

- 최종 전체 141개 테스트 및 20개 서버 파일 구문/정적 참조 검사 통과. 관련 UI 24개/독립 리뷰 15개도 통과했고 리뷰에서 동작·이스케이프·모듈 순환·캐시 누락 회귀가 없었다.
- 가상 서버/격리 브라우저에서 320×812, 375×812 각각 14개 보조 화면, 총 28개 확인 통과. 실제 클릭으로 친구 공개 정보·PIN 팝업·사전 펼침·고객센터 대화·튜토리얼·버전·관리자 인증과 공지 양식을 열었다. 가로 넘침/팝업 넘침/JS 오류 없음, 채팅 대화/입력창/하단 메뉴의 사각형 겹침 없음.
- 높이 568px의 320/375px 채팅 두 검증도 통과했다. 입력 후 전송 버튼 겹침을 수정 전 자동 검증에서 확인했고, 보완 후 입력·실제 가상 전송·설정 탭 이동을 확인했다. economic/home와 support-chat/settings 부모 탭 표시도 보완했다. 실제 기기 OS 키보드 검증을 대신하지 않는다.
- 모바일 fullPage 스크린샷을 반복 생성한 초기 QA는 좌표/스크롤 상태의 영향을 받아 클릭 실패가 있었다. 이를 실제 viewport를 유지한 스크린샷·클릭 검증으로 분리했다. 초기 QA 실패를 운영 휴대폰 버그가 확정된 증거로 사용하지 않는다.
- 상위 `배포자료/20261013_저장오류점검/secondary-final/`에 최종 화면과 results.json, 같은 폴더의 guide-results.json에 전체 서버/짧은 진단 복사와 대체 복사/모바일 안내 표시 결과를 보관한다. 실제 휴대폰 OS 키보드/설치 아이콘/터치/오디오 출력과는 구분한다.
- 서버 저장 수정의 운영 원인은 여전히 미확정이다. 최신 통합 소스 `deploy/server-update.txt`와 상위 `주식왕_서버_0.1.16.gs`를 준비했다. 저장 인자 준비 중 getId 실패도 API 전 실패로 분류하는 추가 회귀 테스트는 수정 전 실패/수정 후 통과를 확인했다. 실제 GAS는 소유자가 코드/서비스 확인 및 기존 배포 새 버전 갱신을 해야 한다.
- 사용자 기존 삭제 기획기록/미커밋 V0_UI_GUIDE/비공개 자료는 제외한다. 실제 계정 로그인·자산 변경·초기화·setupStockKing 실행 없음. 아래 배포 기록은 프런트/공개 소스의 전달 확인이며 GAS 적용과 별개다.
