# 게임 13개 요청 반영 — v0.1.24

## 요청별 반영

1. 출석 팝업의 오른쪽 위 X를 숨기고 수령 완료를 실제 닫기 버튼으로 바꿨다. 미수령 출석과 즉시 수령 흐름은 유지한다.
2. 보상함 상단에 원본 돌아가기 버튼을 추가하고 하단 홈으로/알림함 버튼은 제거했다.
3. 하단 메뉴를 홈 → 뉴스 → 거래소 → 내 자산 → 설정으로 변경했다.
4. 거래 영수증에서 거래 당시 관련 뉴스 표시를 제거했다. 과거 원장과 영수증 데이터를 삭제하지 않았다.
5. 기업 뉴스 본문의 관련 기업 보기 버튼과 해당 하단 연결 그래프를 제거했다.
6. 사용자 PDF는 실제 11개 원본 그림을 포함하므로 기존 11개 업적 분야에 연결했다. 원본 그림·실제 목표·진행률·달성 개수를 카드에 표시하고 펼치면 단계별 기록을 보여 준다. 업적 조건과 기록은 변경하지 않았다.
7. 거래 수량은 수수료 포함 최대 매수 가능 수량 또는 예약에 묶이지 않은 매도 가능 수량으로 제한한다. 서버의 1회 1억 주 상한도 유지한다. +는 가능할 때 초록, -는 가능할 때 빨강이며 불가능할 때 회색이다. 직접 입력 초과는 빨간 수량 초과를 표시한다. 회색 제출 버튼을 눌러도 거래로 진행하지 않고 오류 문구를 짧게 흔든다. 지정가/OCO 손절가는 1~10억 원 정수로 검증한다.
8. 보상 작성창 안에 플레이어 검색·체크박스·이전/다음 페이지·선택 인원과 명단을 추가했다. 선택 없이 지급 확인을 진행할 수 없다.
9. 공지는 전체를 기본으로 하고 대상 직접 선택 시 같은 선택기를 표시한다. 검색/페이지 이동에도 선택을 유지한다.
10. 플레이어 정정 진입 시 서버의 현재 상태를 다시 읽고 현금·DAY·종목별 보유 수량/원가를 채운다. 시장 운영은 관리자 인증을 검증하는 adminMarketState API로 현재 가격·실적·배당 정책을 읽는다. DAY1 일반 화면에 숨겨진 실적을 0으로 가장하지 않는다. dividendOverride를 현재 정책으로 우선한다.
11. 설정의 내 프로필에서 사진·닉네임·소개와 기존 금융 공개 항목을 편집한다. 사진은 브라우저에서 중앙 160px WebP로 축소하고 서버는 이미지 형식과 24KB 한도를 검증한다. 사진·소개는 친구와 검색에 함께 표시한다. 튜토리얼에도 설정 경로를 안내한다. 리셋 시 프로필을 보존하고 계정 삭제는 기존 삭제 경로를 따른다.
12. 친구 순위/목록/요청의 로딩과 빈 상태를 구분한다. 로그인 후 친구·순위·대화 최근 기록을 미리 읽고 캐시를 화면에 즉시 연결한다. 선택 순위 기준으로 재진입 시 올바른 지표를 갱신한다.
13. 친구 대화별 최근10개를 예열하고 대화 진입 시 기본50개 및 더 이전 기록을 보강한다. 예열은 최신 확정 메시지와 미전송 메시지를 지우지 않고 ID로 병합한다. 보강 cursor의 경계와 계정/회차 격리를 검증했다. 열린 대화는 별도2초 주기로 확인하고 앞선 조회가 끝나기 전에 중복 요청하지 않는다. 숨긴 탭에서는 확인을 멈춘다. 실제 수신 시간에는 네트워크·Google 서버 처리 시간이 추가된다.

## 검증과 보존

- 자동 회귀와 서버22파일·HTML/JS/manifest 구문/참조 검사, Git diff 공백 검사. 최종 개수와 배포 결과는 저장소 밖 최신 인수인계 및 `배포자료/20261015_게임개선/`의 최종 JSON/로그에 기록한다.
- 격리 Chrome 320/375/480px에서 업적/출석/보상/친구/프로필/대화/거래/관리자 등21장면의 넘침·이미지·실제 동작을 점검했다. 실행 오류 없음. 대화 예열10개→16개 보강, 사진 저장 후 친구 검색 공개, 초과/잘못된 예약 제출 차단, 관리자 현재값을 검증했다. 실제 운영 계정의 자산/시장/공지/보상을 변경하지 않았다.
- 독립 코드 검토의 순위·최신 채팅 캐시/경계·예약 입력·관리자 실제 실적/배당 정책 지적을 회귀 재현 후 수정했다. 최종 차단 이슈 없음. 스타일 정적 탐지0건.
- 기존 v0.1.23의 금액 모션·즉시 보상·홈 PDF 그림·서체를 보존한다. 기존 기획기록 삭제와 미추적 V0_UI_GUIDE, 원본 PDF/첨부와 운영 비공개 자료를 보존한다.
- 저장 형식2와 기존 장부·API URL 유지. setupStockKing 및 저장소 전환을 실행하지 않는다. 운영 Code.gs는 기록한 서버7 원본과 일치함을 확인하고 비공개 관리자 bootstrap을 새 합본에도 보존했다. 공개 deploy/server-update.txt에는 비공개 함수 정의를 포함하지 않는다.

## 배포 순서

Google 서버의 기존 웹앱을 새 버전으로 갱신한 뒤 프런트엔드를 배포한다. 코드 저장과 통합본 생성만으로 배포 완료를 판단하지 않는다. Google 편집기의 일시 오류/배포 상태를 증거로 남기고, 공개 Pages와 서버 검증을 마친 상태만 최신 인수인계에 완료로 기록한다.
