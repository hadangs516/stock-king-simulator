2026-10-05 사용자 피드백: 기사마다 이미지를 준비해야 하는 방식은 부담이 크므로 사용하지 않는다.

- 특정 기업의 실제 현장을 촬영한 사진으로 소개하지 않는다. 상세 화면에 주제별 공통 삽화임을 표시한다.

## 제작 기록

내장 imagegen으로 생성한 원본 PNG를 사용한다. 외부 사진이나 기업 로고를 복제하지 않았다.
공통 제작 지시: 가상 한국 주식 게임용 3:2 편집 삽화, 사실적인 3D 렌더링, 썸네일에서도 읽히는 구도, 파랑·은색·금색 중심. 글자·숫자·브랜드·로고·워터마크 없음. 특정 실제 기업의 시설로 표현하지 않음.
