## 후속: 중복 로그인 방지 (0.1.6)

앞선 뉴스·UI 작업은 964718c, 2d5e908에 로컬 커밋했다. 이후 사용자 요청으로 중복 로그인 방지를 구현했다.
- PIN 검증 후 기존 유효 세션이 있으면 확인창을 표시하며, 확인 전에는 기존 접속·로그인 통계를 변경하지 않는다.
- 취소/닫기/ESC는 기존 접속 유지. 로그인 확정 시 이전 세션과 관리자 강화 인증·대리 권한을 폐기한다.
- 기존 세션의 조회·거래는 즉시 서버에서 거절. 기존 화면은 다음 요청/15초 동기화 또는 전면 복귀 때 로그아웃 안내로 전환한다.
- 기기 지문 없이 세션 기준. 같은 토큰을 공유하는 탭은 같은 접속이며, 별도 브라우저의 새 로그인은 중복 확인 대상이다. 창을 닫아도 로그인 유지 세션이 유효하면 확인한다.
- 이전 탭이 로그아웃할 때 공유 저장소의 새 로그인 토큰을 지우지 않는다.
- 전체 테스트 85개 및 정적 검사 통과. 로컬 브라우저에서 확인창·취소·확정·이전 화면 로그아웃 안내 확인. 화면 증거는 배포자료/20261006_중복로그인.png.
