# 2026-10-08 UI 재구현 — 0.1.9

이 기록은 이전 UI 완료 설명보다 우선한다. 사용자는 기존 UI 품질을 거절하고 PDF에 충실한 재구현을 요청했다.

## 반영
- 원본 PDF에서 추출한 그림을 사용한 상단/홈/설정/로딩, 촘촘한 거래소·뉴스 목록, 자산·종목 상세·예약주문·보상함·알림함 재구성.
- 기존 거래/예약/친구/차트 기록/계정 기능 유지. 친구 진입점은 출석 표시와 무관하게 유지.
- 사용자 제공 `assets/audio/bmg/main_bmg.mp3` 연결. 반복 재생, 사용자 상호작용 후 재생, 별도 음량 저장, 숨김 시 정지. 합성 음악/효과음 제거. 제공 예정 효과음은 준비 중 표시.
- 새 파비콘 `assets/favicon-transparent.png`: 2026-10-08 사용자가 보낸 398×388 RGBA 파일을 바이트 그대로 복사. 투명도 0~255, 원본과 SHA-256 일치. 링크와 오프라인 캐시 변경. 설치 아이콘과 공유 미리보기는 이번 파비콘 파일로 덮어쓰지 않음.
- 버전 0.1.9, 서비스 워커 캐시 갱신. 모든 브라우저 모듈과 UI 그림 사전 캐시. 음악/뉴스100장은 초기 전체 다운로드 제외.

## 검증
- 전체 113개 테스트 통과. 문법 및 파일 연결 검사 통과(서버 19개 파일 포함).
- 별도 리뷰에서 발견한 친구 진입점, BGM % 갱신, music.js 캐시, 차트 거래/뉴스 버튼 숨김 문제 수정.
- 로컬 Chrome 격리 실행: 320/375px 각각 홈·거래소·자산·뉴스·설정·상세·예약·보상·알림·기사 10화면의 가로 넘침/실행 오류 없음. 매수 입력창 확인.
- 실제 제공 MP3의 src, 35% 음량, 재생 상태 및 화면의 35% 표시 확인. 비공개 운영 데이터/운영 API를 사용하지 않는 임시 데이터 시험.
- 참고 화면/검증 결과: 프로젝트 바깥 `배포자료/20261008_UI대조/current/`. 가상 시험 금액과 이력은 제품 코드에 들어가지 않음.
- 최종 리뷰 추가 수정: 자동 갱신 시 계정/기타 설정·자산 상세 펼침 유지, 기사 화면 뉴스 탭 선택 유지, 모든 보상·배당 수령 범위 명시. 최종 320/375px 브라우저 검증에서 기사 탭 선택/설정 펼침 유지 확인, 관련 11개 테스트 재통과.
- 실제 휴대폰의 터치·키보드·설치·오디오 출력 및 운영 환경 통합 확인은 별도 필요.

## 배포 및 보존
- 이전 98e5581까지는 사용자가 GitHub push 성공한 화면을 전달함. 이전 기록의 “아직 push 안 됨”은 해당 커밋에 적용하지 않는다.
- 이번 0.1.9 UI는 아직 push/운영 배포하지 않음. 서버 로직 변경은 없음. 기존 GAS 0.1.8 반영 여부는 이 작업에서 확인하지 않음.
- 사용자 이동으로 삭제 표시된 기획기록, docs/V0_UI_GUIDE.md 및 그 밖의 오디오 파일 보존. 전체 일괄 스테이징 금지.
- 비공개 관리자 자료와 서버 로그를 열거나 포함하지 않는다. setupStockKing 실행 금지.
- 뉴스100장 작업을 반복하지 않는다. 상장폐지 예고 알림 제외/26종 알림/출석 B안 유지. 아이템·테마와 추가 이미지 생성은 범위 밖.
