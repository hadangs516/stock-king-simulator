# 2026-10-13 원본 품질 복구 / 0.1.15

사용자는 0.1.14 출석창에 참고 사진의 하늘색 게임 화면·주식왕 글자가 그대로 남은 문제를 지적하고 다른 화면의 품질 저하도 찾아 고치도록 요청했다. 이어 설치 아이콘의 그림이 작다고 지적하여 사각형을 크게 채우도록 요구했다. 이 문서가 0.1.13/14의 품질 완료 판단보다 우선한다.

두 UI PDF(13쪽·11쪽), 이전 첨부와 최신 설정/하단 바/출석/로그인/로딩 참고를 실제 검증 화면과 대조했다. 이전 자동 검사는 실행 오류·넘침·보상 동작을 확인했지만, 참고 사진의 배경을 제품에 붙인 잘못과 일러스트 손실을 검출하지 못했다. 이번에는 원본 대조와 실제 화면 확인을 함께 수행했다.

## 보존 및 수정 경계

- 출석 B안(최초 100만원·일반 10만원·주간 50만원·30일 300만원), 수령 즉시 닫기, 서버 확인된 지급/도장, 자동 출석 X/ESC 차단 유지.
- 뉴스 이미지 100장·사용자 BGM 재사용. 신규 뉴스 이미지·효과음 생성 없음. 아이템/테마 미확정 보류, 상장폐지 예고 위험 알림 제외 유지.
- 뉴스/자산/시장 글자 확대와 목록 차트 제거는 사용자 요청이므로 복구 대상에서 제외했다. 현재 하단 바와 입력 폼에 잘림이 없는 로그인도 그대로 유지했다.
- UI 그림은 이미지 편집 도구로 배경/고정 문구를 제거한 별도 버전 자산을 만들고 필요한 부분만 연결했다. 편집 결과는 원본과 대조했으며 픽셀 단위 원본 동일성을 주장하지 않는다. 원본 첨부/기존 파일은 보존했다.
- 서버 소스 변경·운영 계정 접속·데이터 초기화 없음. 기존 사용자 삭제 기획기록·미커밋 `docs/V0_UI_GUIDE.md`·비공개 자료는 커밋에서 제외한다.
- 캐시에서는 실제로 교체된 구 아이콘을 제외하여 중복 다운로드를 줄였다. 뉴스100은 최초 캐시에 넣지 않는다.

## 확인

- 전체 자동 테스트 135개 통과. 이후 작은 그림/펼침 상태 보완에 관련 7개 테스트 재검증 통과. 문법·19개 서버 파일·정적 참조 검사 통과.
- 320/375px 각각 주요 11화면과 메뉴 상태/정렬/입력/오디오 등 총 38개 확인 결과 실패 없음. 가로 넘침·배너 침범·실행 오류 없음. 매수·매도·예약, 수량 ＋/−/최대 입력, 회사 설명·총자산 계산의 펼침 상태 유지 확인.
- 320×667 / 375×740 / 320×568 / 440×900 출석: 30칸 내부 스크롤 없음, 자동 X/ESC 차단, 즉시 닫힘·서버 지급·수동 다시 열기·도장 확인.
- 320/375px 최초 HTML·로그인/로딩 원본 비율, 팁 5초 교체 및 최장 문구가 카드 안에 표시됨, 로그인 첫 터치 BGM 확인.
- 채팅 pending→서버 확인→sent 1초, 캐시 즉시 재입장, 화면 이동 조회 취소, 읽음 오프라인→새로고침→연결 재시도 검증 통과.
- 투명 외곽이 필요한 자산 15개에 실제 alpha 픽셀과 네 모서리 투명 확인. 디자인 검사 발견 항목 0은 품질 판단의 보조 증거이며 원본 대조를 대신하지 않는다.
- 별도 코드 리뷰: 새 펼침 영역이 갱신 때 닫히는 P2를 발견하여 종목별 `data-panel`로 고쳤고 브라우저에서 확인했다. 중대한 거래/출석 회귀·모듈 순환·빠진 캐시 파일 없음.
- 증거: 상위 `배포자료/20261012_원본품질복구/`의 검증 스크립트·screens/results.json·스크린샷·투명성 검사·디자인 검사. 실제 운영 계정을 쓰지 않는 격리 브라우저/가상 서버이며 실제 휴대폰 OS 설치 아이콘·키보드·터치와 구분한다.

최종 프런트 배포 결과는 같은 증거 폴더의 `deployment.json`, `public-verification.json`과 상위 인수인계 최신 항목에 기록한다. 서버 조회 최적화·주가 변동 확대의 운영 GAS 적용 확인은 기존 안내대로 별도다.
